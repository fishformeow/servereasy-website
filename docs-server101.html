Server 101

The absolute basics, explained without assuming you already know them.

What is a server?

A server is just a computer that stays on and shares something — files, a website, or a game world — with other devices over the internet or a local network.

Cloud vs. on-site: what's the difference?

A cloud server runs on our hardware, so there's nothing in your home or office. An on-site server is physical equipment we install for you, which some businesses prefer for control or compliance reasons.

Which one do I need?

If you're not sure, start with cloud hosting — it's cheaper to try and easy to change later. Visit Hosting to compare plans.
